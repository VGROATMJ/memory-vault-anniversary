CARA EDIT MEDIA
- Tekan tombol ✦ di kanan atas, atau tombol Kelola foto
- Pilih tab Foto / Video / Musik
- Tambah, hapus, atau geser urutan
- Tekan ✂ pada foto untuk crop / zoom / geser framing / rotasi
- Tekan ↔ pada dua foto untuk menukar posisi keduanya
- Perubahan tersimpan otomatis di browser yang dipakai

CATATAN
Perubahan lewat editor browser tidak menulis ulang file ZIP. Jadi media awal tetap aman.
Kalau mau mengganti nama dan teks permanen, edit config.js.
